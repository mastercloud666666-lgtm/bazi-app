# 云子文化 · 小红书内容矩阵策略

## 一、平台定位

**账号人设：** 一个会八字的朋友，不端着，说人话，帮你用命理看清楚真实处境
**内容基调：** 温暖实用，不神秘化，不吓唬人，不"大师腔"
**目标用户：** 25-38岁华人女性为主，面临情感/事业/人生决策困惑，对命理半信半疑但好奇

---

## 二、内容五大支柱

### 支柱1：「你现在的困境，命理是这么解读的」
对应文章：shilian / hunyin-weiji / shiye-bushun / caiyun-cha / jiating-maodun
格式：问题切入 → 命理解释 → 1个立即可用的行动
发布频率：每周2篇

### 支柱2：「今年/这个阶段，你适合做什么」
对应文章：jinnian-shihe-* / shenme-shihou-* / weilai-* 系列
格式：时间锚点 + 决策框架（换工作/结婚/买房/要孩子）
发布频率：每周1篇

### 支柱3：「这些命理信号，你中了几个」
对应文章：zongshi-yudao-lantaohua / hehuo-fengxian / po-cai / taisui-chongke
格式：清单式，「5个信号」「3种表现」，互动性强
发布频率：每周1篇

### 支柱4：「感情类专题」（最高互动）
对应文章：ganqing-* / fuhe-* / hepan-* / nvming-* 系列
格式：故事感强，「如果你正在经历…」开头
发布频率：每周2篇

### 支柱5：「命理知识科普」（建立权威）
对应文章：bazi-rumen / dayun-jiexi / bazi-geju / yongshen 等
格式：干货卡片，简单易懂，适合收藏
发布频率：每周1篇

## 三、爆款标题公式

**公式1：数字+场景**
「3个八字信号，说明你今年财运要爆发」
「5种日柱，感情运天生就好」

**公式2：反常识**
「努力了还是不成功？可能是运势时机没到」
「分手了不一定是感情结束，命理是这样说的」

**公式3：直接问句**
「今年适合换工作吗？先看你的大运再决定」
「总是遇到烂桃花，八字里早就写明原因了」

**公式4：身份锁定**
「婚姻冷漠的女生，可能是这种命局」
「30岁还没找到方向的人，八字往往有这个特征」

## 四、帖子结构模板

### 模板A：困境解读型（支柱1/4）
```
[标题]
第1-3行：场景共情（不解释命理，先说感受）
---
正文：
• 这种情况在命理里叫做…（1句话解释）
• 为什么会这样：[核心原因，1-2点]
• 命理上的转机信号：[具体说]
• 现在可以做的一件事：[可操作]

🔮 想知道你的具体情况，主页有免费测算入口
#八字命理 #命理解读 #[具体话题标签]
```

### 模板B：时机决策型（支柱2）
```
[标题]
第1-3行：「很多人问我今年XX，其实答案在八字里」
---
正文：
• 适合的命理条件是什么
• 不适合的信号有哪些
• 怎么自查（简单方法）
• 不确定的可以测一下

🔮 主页测算
#今年运势 #[决策话题]
```

### 模板C：信号清单型（支柱3）
```
[标题] 「X个信号说明你的XXX」
---
正文（列表式）：
✅ 信号1：…
✅ 信号2：…
✅ 信号3：…
中了3个以上：[说明]
中了1-2个：[说明]
0个：[说明]

评论区说说你中了几个👇
#八字 #[话题]
```

## 五、话题标签策略

**固定标签（每帖必带）：**
#八字命理 #命理解读 #云子命理

**轮换标签（按内容类型）：**
- 感情类：#感情运势 #八字合婚 #桃花运 #感情测算
- 事业类：#事业运势 #八字看事业 #工作运
- 财运类：#财运测算 #八字财运
- 决策类：#今年运势 #流年大运 #命理决策
- 通用互动：#玄学 #命理 #生辰八字 #算命

**蹭热点标签：**
每月根据社会话题加1-2个热门标签（相亲季、毕业季、年终奖期等）
