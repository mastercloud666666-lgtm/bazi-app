内测入口

文案 Agent 会审台

面向短视频口播创作者的标题、文案、去 AI 味和多 Agent 会审工作台。当前入口用于内测演示，正式使用前需要先启动对应服务。

打开会审台 新窗口打开

如果页面无法打开，说明 `agent.tengyunzi.com` 尚未配置或本地 Agent 服务没有启动。

工作流

  1. 1
    生成标题 按人设、赛道和短视频停留逻辑生成候选标题。
  2. 2
    生成文案 围绕真实经历、低谷、财富焦虑和人性洞察生成口播稿。
  3. 3
    多 Agent 会审 从钩子、创伤识别、去 AI 味、节奏和边界安全打分。
  4. 4
    改写优化 保留真实感，强化停留、评论、收藏和转发触发。
不影响主站

这是独立静态入口页，部署后地址为 `/copy-agent.html`，不会改动首页和现有八字功能。

需要服务映射

正式访问需要把 `agent.tengyunzi.com` 映射到文案 Agent 服务，推荐使用 Cloudflare Tunnel 内测。

后续可商业化

验证需求后，可以升级为登录、额度、付费和云端 API 的正式 SaaS 版本。
