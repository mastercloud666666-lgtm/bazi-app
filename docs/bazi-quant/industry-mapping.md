# 行业五行映射表（细化版）

> 基于申万行业分类，细化至二级行业。
> 分类原则：**有实体产品 = 阳，无实体/服务/信息/资本流通 = 阴**

---

## 总览：一级行业快查

| 五行 | 阳（有实体） | 阴（无实体） |
|------|------------|------------|
| 木 | 农林牧渔（部分）、纺织服装、轻工制造、医药（制药/器械）、电力设备 | 医疗服务、环保服务 |
| 火 | 煤炭、石油石化（上游）、公用事业（电力/燃气） | 计算机软件、传媒、互联网 |
| 土 | 食品饮料、基础化工、建筑材料、建筑装饰（施工）、房地产（开发） | 社会服务、物业管理 |
| 金 | 钢铁、有色金属、机械设备、家用电器、电子硬件、国防军工 | 银行、保险、证券 |
| 水 | 交通运输（港口/航运）、公用事业（水务） | 商贸零售、通信运营商、美容护理 |

> 注：部分一级行业内部存在五行分裂，以二级行业为准。

## 跨五行行业汇总（重要）

以下一级行业内部存在五行分裂，投资时需细化到二级：

| 一级行业 | 二级行业分裂情况 |
|---------|---------------|
| 农林牧渔 | 木阳（种植/林/牧）+ **水阳（渔业）** |
| 纺织服装 | 木阳（天然纤维）+ **土阳（化纤）** |
| 医药生物 | 木阳（制药/生物制品）+ **金阳（医疗器械）** + **木阴（医疗服务/CXO）** |
| 公用事业 | 火阳（电力/燃气）+ **水阳（水电/水务）** |
| 石油石化 | 火阳（开采）+ **土阳（化工下游）** + **金阳（油服设备）** + **水阳（管道）** |
| 计算机 | 火阴（软件/AI）+ **金阳（硬件/服务器）** |
| 建筑装饰 | 土阳（施工）+ **土阴（装修服务）** + **金阳（工程机械）** |
| 通信 | 水阴（运营商）+ **金阳（设备）** + **土阳（工程）** |
| 社会服务 | 土阴（酒店/餐饮）+ **水阴（旅游）** + **木阴（教育）** |
| 食品饮料 | 土阳（食品/白酒）+ **水阴（饮料）** |
| 交通运输 | 水阳（航运/港口/公路）+ **金阳（铁路）** + **水阴（快递/物流）** |
| 国防军工 | 金阳（航天/航空/兵装）+ **水阳（舰船）** |
| 传媒 | 火阴（互联网/影视/游戏）+ **木阴（出版）** |
| 电力设备 | 木阳（光伏/风电/储能）+ **金阳（电网设备）** |

## 财星属性参考（按五行）

| 五行 | 典型行业 | 财星属性 | 投资特征 |
|------|---------|---------|---------|
| 金阳 | 钢铁、有色、机械 | 偏财 | 强周期，波动大，适合短中线博弈 |
| 金阴 | 银行、证券、保险 | 正财 | 稳定分红，防御性，适合长线持有 |
| 火阳 | 煤炭、石油、电力 | 偏财 | 大宗周期，暴涨暴跌 |
| 火阴 | 软件、AI、传媒 | 成长 | 高估值高成长，轻资产扩张 |
| 木阳 | 农业、医药、新能源 | 成长/偏财 | 政策成长逻辑，长坡厚雪 |
| 木阴 | 医疗服务、环保 | 正财 | 稳健服务，现金流稳定 |
| 土阳 | 食品、房地产、基建 | 偏财/正财 | 食品正财；地产/基建强周期偏财 |
| 土阴 | 酒店、餐饮 | 正财 | 稳定消费服务 |
| 水阳 | 航运、港口 | 偏财 | 航运周期波动极大 |
| 水阴 | 零售、通信运营商 | 正财 | 稳定流量收入，适合长线 |
