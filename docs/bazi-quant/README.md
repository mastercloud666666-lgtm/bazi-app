## 2. 行业五行映射表

### 分类原则

- **阳**：有实体产品（矿产、设备、建筑、食品等）
- **阴**：无实体、以服务/信息/资本流通为主（软件、金融、传媒等）

### 申万行业 × 五行 × 阴阳

| 五行 | 阳（有实体） | 阴（无实体） |
|------|------------|------------|
| 木 | 农林牧渔、纺织服装、轻工制造、医药生物、电力设备（光伏储能硬件） | 环保（服务为主） |
| 火 | 煤炭、石油石化、公用事业（电网基础设施） | 计算机（软件数据）、传媒（内容信息） |
| 土 | 食品饮料、基础化工、建筑材料、建筑装饰、房地产 | 社会服务（旅游酒店教育） |
| 金 | 钢铁、有色金属、机械设备、家用电器、电子（芯片元器件）、国防军工 | 银行、保险、证券（非银金融） |
| 水 | 交通运输（港口铁路船舶） | 商贸零售、通信、美容护理 |

> 综合类（多元化企业）不做单一标注。

## 3. 第一层：命局强弱评分

### 3.1 各柱位权重

| 柱位 | 权重 |
|------|-----|
| 月令（月支） | 40 分 |
| 月干 | 12 分 |
| 日支 | 12 分 |
| 时干 | 12 分 |
| 时支 | 12 分 |
| 年干 | 8 分 |
| 年支 | 4 分 |
| **总计** | **100 分** |

### 3.2 计分规则

**月令：**
```
月令是日主比劫（同五行）→ 40 分
月令是日主印星（生我者）→ 40 分
月令是其他（财/官/食伤）→ 0 分
```

**其余柱位（年干/年支/月干/日支/时干/时支）：**
```
该字是日主比劫（同五行）→ 按权重计分
该字是日主印星            → 0 分（印星仅月令有效）
该字是其他（财/官/食伤）  → 0 分
```

遇三合、三会、六合等结构，按第 9 节能量倍数表加成。

### 3.3 身强弱判断阈值

| 得分区间 | 判断 | 喜用神 |
|---------|------|-------|
| > 60 | 身强 | 财星 + 官杀 |
| < 40 | 身弱 | 印星 + 比劫 |
| 40 - 60 | 中和 | 月令是否得令为决定性参考 |
| 特殊格局（从格等） | 单独判断 | 按格局喜用 |

## 4. 第二层：财星能量分析

### 4.1 正财与偏财定义

```
日主克的五行 = 财星
  阴阳相异 → 正财（甲克己 / 乙克戊）
  阴阳相同 → 偏财（甲克戊 / 乙克己）
```

### 4.2 财星能量计算

每个财星字的能量 = 柱位基础分 × 加成倍数

| 条件 | 能量加成 |
|------|---------|
| 财星在地支，天干有同五行透出 | × 2 以上（透出引化） |
| 财星在天干，地支有通根 | × 2 以上（根气稳固） |
| 财星地支形成三合 / 三会 | 参考第 9 节倍数表 |
| 财星地支形成半三合 / 六合 | 参考第 9 节倍数表 |
| 财星被六冲 | 能量削弱 |
| 财星被合化为他神 | 财星消失，不计入 |

### 4.3 正偏财比重判断

```
正财总能量 vs 偏财总能量
  正财 > 偏财（差距 ≥ 20%）→ 正财型
  偏财 > 正财（差距 ≥ 20%）→ 偏财型
  差距 < 20%               → 混合型
```

### 4.4 投资风格映射

| 财星类型 | 投资风格 | 对应策略 |
|---------|---------|---------|
| 正财为主 | 稳健长线 | 高股息、价值股、长周期持有 |
| 偏财为主 | 灵活博弈 | 成长股、周期股、短中线进出 |
| 混合型 | 核心 + 卫星 | 底仓价值股 + 部分成长博弈 |

### 4.5 无财星兜底规则

```
命局无财星或财星能量极弱
  ↓
第一顺位：官杀星
  官星强 → 稳健型（类正财逻辑）
  杀星强 → 激进型（类偏财逻辑）
  ↓
第二顺位：神煞禄神所在五行
  ↓
第三顺位：
  身强者 → 财库地支所在五行
  身弱者 → 比劫库地支所在五行
```

## 5. 第三层：流年大运动态评分

### 5.1 基础评分规则

```
每个天干或地支字 = 基础 10 分（1 倍）
遇合化结构 → 按第 9 节倍数表计算
```

**关键规则：** 流年/大运的字与**命局已有结构**合并判断。  
例：命局有申辰，大运来子 → 申子辰三合水成立，子不按 10 分，按三合规则计算。

### 5.2 喜用净分计算

```
当期喜用得分 = 喜用神五行字/结构得分之和
当期忌神得分 = 忌神五行字/结构得分之和
净得分 = 喜用得分 - 忌神得分
```

### 5.3 财多身弱动态修正

**触发条件：** 命局财多身弱（静态基础分 < 40）

```
流年/大运带入比劫或印枭
    ↓
计算比劫/印枭动态能量分（含合化倍数）
    ↓
当期有效身强弱分 = 命局基础分 + 动态加分
    ↓
按下表重新判断取财能力
```

| 当期有效身强弱分 | 取财能力 | 投资信号 |
|---------------|---------|---------|
| < 40 | 无法承财 | 保守，回避财星对应行业 |
| 40 - 55 | 可小取 | 轻仓介入，控制仓位 |
| 55 - 70 | 可正常取 | 正常配置财星行业 |
| > 70 | 可积极取 | 加重财星行业配置 |

### 5.4 四层周期权重

| 周期 | 时间跨度 | 作用 | 权重 |
|------|---------|------|-----|
| 大运 | 10 年 | 大方向，板块选择 | 35% |
| 流年 | 1 年 | 年度配置方向 | 45% |
| 流月 | 1 月 | 建仓/加仓/减仓时机 | 15% |
| 流日 | 1 天 | 具体买卖执行日 | 4% |
| 流时 | 2-3 小时 | 盘中执行时段 | 1% |

## 6. 第四层：时机信号（流月流日）

### 6.1 流月信号：决定本月能否操作

| 流月特征 | 本月操作指引 |
|---------|------------|
| 喜用月（三合三会，能量高） | 积极建仓，可重仓 |
| 喜用月（单字，普通） | 正常建仓，标准仓位 |
| 中性月 | 持仓观望，不新增 |
| 忌神月（单字） | 减仓，不入场 |
| 忌神月（三合三会，能量高） | 清仓或空仓 |

**财库冲开规则：**
```
命局地支有财库（辰戌丑未藏财）
  ↓
流月来冲（六冲）→ 财库打开
  身强者 → 加分，可取财，加仓信号
  身弱者 → 减分，财被冲散，减仓信号
```

### 6.2 流日信号：决定具体执行时机

**入场逻辑：**
```
流月 = 喜用（方向已定）
    ↓
流日 = 喜用 → 执行建仓 / 加仓
流日 = 中性 → 可操作，优先等喜用日
流日 = 忌神 → 延迟，等下一个喜用日
```

**出场逻辑：**
```
流月 = 忌神（需要退出）
    ↓
流日 = 忌神 → 立即执行减仓 / 清仓
流日 = 喜用 → 借反弹出货，逢高减仓
流日 = 中性 → 按计划逐步减仓
```

### 6.3 四层周期综合信号矩阵

| 大运 | 流年 | 流月 | 流日 | 流时 | 信号强度 | 操作 |
|------|------|------|------|------|---------|------|
| 喜 | 喜 | 喜 | 喜 | 喜 | 五层共振 | 满仓，全力建仓 |
| 喜 | 喜 | 喜 | 喜 | 忌/刑冲 | 强势但时段危险 | 建仓，换时段执行 |
| 喜 | 喜 | 喜 | 忌 | — | 强势稍杂 | 建仓，等喜用流日 |
| 喜 | 喜 | 忌 | 喜 | — | 方向对月份逆 | 持仓，不加仓 |
| 喜 | 忌 | 喜 | 喜 | — | 流年逆势 | 轻仓谨慎 |
| 忌 | 忌 | 忌 | 忌 | 忌 | 全面逆势 | 空仓 |
| 忌 | 喜 | 喜 | 喜 | — | 大运差流年补救 | 小仓短线 |

### 6.4 时机综合评分公式

```
时机总分 =
  大运喜用净分 × 0.35
+ 流年喜用净分 × 0.45
+ 流月喜用净分 × 0.15
+ 流日喜用净分 × 0.04
+ 流时喜用净分 × 0.01

时机总分 > 70  → 建仓 / 加仓
时机总分 50-70 → 轻仓或持仓观望
时机总分 30-50 → 观望
时机总分 < 30  → 减仓 / 清仓

注：流时有刑冲信号时，无论总分多高，当前时段禁止建仓
```

### 6.5 合化结构对时机的特殊加成

```
流月天干 + 流日天干 → 形成天干合
  合化为喜用五行 → 强烈买入信号
  合化为忌神五行 → 强烈卖出信号

流月地支 + 命局地支 → 形成三合 / 六合
  合化喜用 → 当月持续买入信号
  合化忌神 → 当月持续减仓信号
```

### 6.6 流时：盘中交易时段信号

#### A 股交易时段与时辰对应

A 股每日交易时间落在三个时辰内：

| 时段 | 时间 | 时辰 | 地支 | 五行 | 藏干 |
|------|------|------|------|------|------|
| 上午开盘 | 09:30 - 11:00 | 巳时 | 巳 | 阴火 | 丙火、庚金、戊土 |
| 午盘尾段 | 11:00 - 11:30 | 午时前半 | 午 | 阳火 | 丁火、己土 |
| 下午全场 | 13:00 - 15:00 | 未时 | 未 | 阳土 | 己土、丁火、乙木 |

**结构性事实：巳 + 午 + 未 = 三会火局**

整个交易日（9:00-15:00）完整覆盖巳午未三会火，火的能量贯穿全天。
- 喜火者（火为喜用）→ 交易日整体有利
- 忌火者（火为忌神）→ 需依赖天干引化判断具体时段

#### 流时天干推算（日上起时法）

| 日干 | 子时起 | 巳时天干 | 午时天干 | 未时天干 |
|------|-------|---------|---------|---------|
| 甲 / 己 | 甲子 | **己巳** | **庚午** | **辛未** |
| 乙 / 庚 | 丙子 | **辛巳** | **壬午** | **癸未** |
| 丙 / 辛 | 戊子 | **癸巳** | **甲午** | **乙未** |
| 丁 / 壬 | 庚子 | **乙巳** | **丙午** | **丁未** |
| 戊 / 癸 | 壬子 | **丁巳** | **戊午** | **己未** |

#### 流时评分规则

基础分：每个时辰 = **5 分**（流日的一半，时间粒度更小）

**核心原则：流时以天干为主，地支有条件参考**

```
流时天干 → 主要分析对象
  每天不同，是盘中时段的核心信号
  直接按喜用 / 忌神判断，计入得分

流时地支（巳 / 午 / 未）→ 有条件参考
  仅在以下情况才纳入分析：
    ① 流时地支 与 命局地支 形成合化（三合/三会/六合/半三合）
    ② 流时地支 与 流日地支 形成合化
    ③ 流时地支 与 命局/流日地支 形成刑冲（六冲/三刑/自刑）
  无上述关系 → 地支不计分，不参考
```

#### 各时段信号详解

**分析顺序：先看天干喜忌，再查地支有无合化/刑冲**

#### 建仓 / 加仓最优时间窗口

```
最优建仓条件（全部满足）：
  大运 + 流年 + 流月 + 流日 均为喜用
  AND
  流时天干地支为喜用
  AND
  流时与流日 / 命局无刑冲破害
  → 该时段全力建仓

次优建仓条件：
  大运 + 流年 + 流月 为喜用
  流日为喜用，流时中性或轻度喜用
  → 正常建仓，不必等到最优时段

可操作下限：
  流月喜用 + 流日喜用 + 流时中性
  → 轻仓建仓，避开刑冲时段

不可建仓：
  流时地支与流日 / 命局形成六冲 / 三刑 / 自刑
  → 即使流日喜用，该时段也暂缓执行
```

#### 减仓 / 清仓最优时间窗口

```
计划清仓（大周期已触发清仓信号）：
  选 流月喜用 + 流日喜用 的日期
  在该日 巳时或午时 开盘后逢高出货
  → 借喜用时段的流动性和价格优势出场

被迫清仓（忌凶流月 + 忌凶流日）：
  选 刑冲最少的时段 执行
  优先 未时（下午场）收盘前减仓
  → 避开开盘剧烈波动

紧急清仓信号：
  流时地支与命局财星地支形成六冲
  → 财库被冲，身弱者立即清仓，不等收盘
```

#### 刑冲破害的危险时段

以下情况该时段不宜操作，等待下一时段或次日：

| 危险信号 | 来源 | 处理 |
|---------|------|------|
| **流时天干 = 忌神** | 天干（必查） | 该时段禁止建仓，可出货 |
| **流时天干合化 → 忌神五行** | 天干（必查） | 严格禁止建仓 |
| 流时地支 冲 命局喜用地支 | 地支（有触发才查） | 暂停操作，换时段 |
| 流时地支 冲 流日地支 | 地支（有触发才查） | 等下一时段 |
| 流时地支 三刑 命局/流日地支 | 地支（有触发才查） | 只减仓不建仓 |
| 流时地支 自刑（流日同支） | 地支（有触发才查） | 禁止操作 |
| 巳午未三会火 + 火为忌神 + 天干引化 | 地支三会（有触发才查） | 当日仅做减仓 |

#### 每日交易决策输出示例

2025年3月15日 乙卯月 丙寅日

流日分析：
  丙火（天干）= 忌神（甲木身强，丙火为食伤）→ -10

    净分：+5（可操作）

## 8. 两层系统的平衡与决策权重

### 8.1 两层系统的本质差异

两层系统测量的是完全不同的维度，不能简单相加：

| | 宏观经济层 | 八字命局层 |
|--|-----------|---------|
| 测量的是什么 | 外部机会是否存在 | 你是否处于能抓住机会的状态 |
| 适用范围 | 所有人相同 | 每个人不同 |
| 可验证性 | 可回测，数据驱动 | 规则确定，个人验证 |
| 失效后果 | 选错方向，逆势而为 | 时机错误，方向对也拿不住 |

> 宏观 = 天气（今天适不适合出海）  
> 八字 = 状态（你今天有没有能力出海）  
> 两者必须同时具备，才能有收获。

### 8.2 核心原则：乘法逻辑，非加法逻辑

固定比例相加（50% + 50%）的问题：

```
宏观极差 + 八字极好 → 总分 50
宏观极好 + 八字极差 → 总分 50
```

两种情况得分相同，但结论截然不同：
- 宏观极差时，系统性风险无法靠个人运势对抗
- 八字极差时，市场再好也容易频繁误判、拿不住

**正确逻辑：两者是乘法关系，任一方极弱都大幅压低结果。**

### 8.3 层级门控机制

**宏观作为"场"（必要条件，决定能不能玩）：**

```
宏观分 < 20/50 → 系统性风险期
  → 无论八字多好，最大仓位上限 15%

宏观分 20-35  → 震荡分化期
  → 八字信号决定是否入场，仓位适中

宏观分 35-50  → 趋势明确期
  → 八字信号决定方向和时机，仓位充分
```

**八字作为"人"（方向与时机，决定怎么玩）：**

```
八字分 < 20/50 → 个人逆势期
  → 无论宏观多好，最大仓位上限 20%

八字分 20-35  → 平稳期
  → 跟随宏观，保守配置

八字分 35-50  → 个人顺势期
  → 主动出击，充分配置
```

### 8.4 仓位计算公式

```
基础仓位 = (宏观分 / 50) × (八字分 / 50) × 100%
最终仓位 = min(基础仓位, 宏观上限, 八字上限)
```

| 宏观分 | 八字分 | 基础仓位 | 备注 |
|-------|-------|---------|------|
| 45 | 45 | 81% | 双强共振，满仓 |
| 40 | 45 | 72% | 正常配置 |
| 20 | 45 | 36% | 宏观拖累 |
| 40 | 20 | 32% | 八字拖累 |
| 15 | 50 | 触发上限 → 15% | 宏观封顶 |
| 10 | 10 | 4% → 近空仓 | 双弱，观望 |

### 8.5 角色分工

| 决策维度 | 主导层 | 辅助层 |
|---------|-------|-------|
| 投资哪个行业 | 八字喜用五行 | 宏观景气筛选 |
| 什么时候入场 | 纯八字（流月流日） | 宏观趋势确认 |
| 持有多久 | 八字大运流年周期 | 宏观周期长度 |
| 仓位多大 | 两者共同决定（乘法） | — |

### 8.6 行业选择：取交集

```
集合 A = 八字喜用五行对应行业
集合 B = 宏观景气支持行业

A ∩ B 有交集 → 双重共振，重点配置
A 有 B 无    → 个人方向对但宏观不支持，轻仓等待
B 有 A 无    → 宏观机会但非个人方向，不参与
A ∩ B 均无   → 空仓
```

### 8.7 动态权重：随操作周期变化

不同时间跨度，两层影响力不同：

| 操作周期 | 宏观权重 | 八字权重 | 原因 |
|---------|---------|---------|------|
| 流日（短线） | 20% | 80% | 宏观不在日频变化 |
| 流月（中线） | 40% | 60% | 流月信号为主 |
| 流年（年度） | 50% | 50% | 两者权力相当 |
| 大运（3年+） | 65% | 35% | 长周期宏观更决定性 |

### 8.8 两者冲突时的处理原则

```
情况一：八字极好 + 宏观极差
  → 宏观代表系统性环境，不可逆抗
  → 保持空仓或极低仓，等待宏观转向
  → 八字好 = 判断力在线，用于研究准备而非重仓操作

情况二：八字极差 + 宏观极好
  → 可参与但仓位压低至上限 20%
  → 用指数 ETF 代替个股（降低决策要求）
  → 避免频繁操作，减少错误次数

情况三：两者均好但行业不重合
  → 以八字喜用五行行业为主仓
  → 宏观景气行业作为短线机会，轻仓参与，不超过 20%
```

## 9. 持仓周期与股票类型判断

### 9.1 长中短线判断框架

持仓周期由**四个因素**综合决定，优先级从高到低：

**第一优先：大运顺逆**
```
大运顺势（喜用）→ 可以持有到大运结束，支持长线
大运逆势（忌神）→ 最多做到流年级别，不宜长线
```

**第二优先：正财 or 偏财格**
```
正财格 → 天然倾向长线稳健持有
偏财格 → 天然倾向中短线博弈进出
```

**第三优先：流年质量**
```
大运顺 + 流年也顺 → 持有周期可延长至当前流年结束
大运顺 + 流年逆  → 缩短至流月级别，及时止盈
```

**第四优先：宏观机会性质**
```
结构性机会（国产替代、能源转型）→ 支持长线，周期以年计
周期性机会（大宗商品涨价）     → 支持中线，周期以季度计
事件驱动（政策刺激、热点）     → 支持短线，周期以周月计
```

**综合判断矩阵：**

| 大运 | 正偏财 | 流年 | 宏观机会 | 建议周期 |
|------|-------|------|---------|---------|
| 顺 | 正财 | 顺 | 结构性 | 长线（3年以上） |
| 顺 | 正财 | 顺 | 周期性 | 中长线（1-3年） |
| 顺 | 偏财 | 顺 | 任意 | 中线（3-12个月） |
| 顺 | 正财 | 逆 | 任意 | 中短线（1-3个月） |
| 顺 | 偏财 | 逆 | 任意 | 短线（流月操作） |
| 逆 | 任意 | 顺 | 任意 | 短线（不超过3个月） |
| 逆 | 任意 | 逆 | 任意 | 空仓或极轻仓 |

---

### 9.2 成长股 vs 分红股判断框架

由**身强弱 × 正偏财 × 宏观阶段**三者共同决定：

**八字维度：**

| 命局特征 | 倾向 | 原因 |
|---------|------|------|
| 身强 + 偏财格 | 成长股 | 日主强，可承受高波动，偏财喜博弈 |
| 身强 + 正财格 | 价值成长兼顾 | 稳健取财，但有余力追求增值 |
| 身弱 + 正财格 | 高股息分红 | 日主弱，不宜承受波动，正财求稳 |
| 身弱 + 偏财格 | 高股息分红 | 偏财虽活跃但身弱无力驾驭，求稳为主 |
| 财多身弱 | 高股息防御 | 财星过旺反成压力，分红型摊薄风险 |
| 流年比劫补足身弱 | 可适当转向成长 | 临时补强，可小仓位参与，不宜重仓 |

**宏观维度修正：**

| 宏观阶段 | 修正方向 |
|---------|---------|
| 复苏期 | 成长股开始布局，适合身强偏财者 |
| 扩张期 | 成长股最佳，身强者充分参与 |
| 过热期 | 成长转分红，逐步移向高股息价值股 |
| 衰退期 | 高股息防御为主，无论八字如何 |

**综合决策：**

```
最终类型 = 八字倾向 × 宏观修正

示例：
  身强偏财 + 扩张期 → 重仓成长股
  身强偏财 + 衰退期 → 降低成长仓位，转向价值股
  身弱正财 + 扩张期 → 以分红为主，少量成长做卫星仓
  身弱正财 + 衰退期 → 纯高股息防御，空仓等待
```

---

### 9.3 长期持仓的清仓信号

长期持仓建立后，以下流年信号触发强制评估：

**身强者：遇比肩劫财流年 → 清仓**

```
身强者喜用为财官
比肩劫财 = 忌神 = 劫我之财

流年天干或地支出现比肩劫财
  + 与命局或大运形成合化（能量放大）
  → 强制清仓，锁定利润

逻辑：劫财字面意为"劫夺财富"，
      身强遇劫财年，持有的收益容易被市场"劫走"
```

**身弱者：遇食伤、官杀流年 → 清仓或减仓**

```
身弱者喜用为印星比劫
食伤 = 泄日主之气（身弱更弱，无力驾驭财）
官杀 = 克日主（身弱受压，决策力下降）

流年带食伤 → 减仓 50% 以上
流年带官杀 → 清仓或降至最低仓位（10% 以内）
流年食伤 + 官杀同现 → 清仓

逻辑：身弱者在泄气或受克年份，
      持仓的判断力和承受力均下降，
      即使账面盈利也应优先保本
```

**补充：其他触发清仓/减仓的信号**

| 情况 | 操作 |
|------|------|
| 身强遇食伤流年（财被泄） | 减仓 30-50% |
| 身弱遇财星旺年（财多身弱加剧） | 减仓 50%，不加仓 |
| 宏观进入衰退期（任何八字） | 减仓至防御仓位 |
| 流年忌神 + 宏观同步转差 | 无条件清仓 |
| 大运切换至忌神大运首年 | 评估全部持仓，逐步清退 |

**清仓的执行时机：**
```
确认清仓信号后
  → 不在流日忌神日执行（避免踩踏）
  → 选流月喜用月 + 流日喜用日逢高出货
  → 如情况紧急（宏观崩溃）则忽略流日，立即执行
```
